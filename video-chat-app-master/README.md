## Concepts Learned

### What is TypeScript?

TypeScript is JavaScript with type safety.

Example:

```ts
const name: string = "Pooja";
```

Benefits:

- Better code quality
- Fewer runtime bugs
- Better IDE support

---

### What is tsconfig.json?

Configuration file for TypeScript.

Controls:

- How code is compiled
- Module system
- Strictness rules
- Output folder

---

### Important tsconfig Options

#### target

```json
"target": "ES2020"
```

Determines JavaScript version generated by TypeScript.

---

#### module

```json
"module": "Node16"
```

Defines how imports and exports work.

---

#### moduleResolution

```json
"moduleResolution": "Node16"
```

Defines how TypeScript finds imported files.

---

#### rootDir

```json
"rootDir": "./src"
```

Source code location.

---

#### outDir

```json
"outDir": "./dist"
```

Compiled JavaScript output location.

---

#### strict

```json
"strict": true
```

Enables strict type checking.

---

### What is Express?

Express is a Node.js framework used to:

- Create APIs
- Handle requests
- Manage routes

---

### What is a Health Route?

Endpoint:

```http
GET /api/health
```

Purpose:

Check whether the backend is alive and functioning.

Response:

```json
{
  "success": true,
  "message": "Server is running"
}
```

---

### What are Environment Variables?

Stored in:

```env
PORT=5000
```

Purpose:

Keep configuration and secrets outside source code.

---

## Errors Encountered

ECMAScript imports and exports cannot be written in a CommonJS file

### Cause

### Fix

```json
"module": "Node16",
"moduleResolution": "Node16"
```

---

## Concepts Learned

### What is MongoDB?

NoSQL database used to store:

- Users
- Messages
- Meetings
- Friends
- Notifications
- AI Summaries

---

### What is MongoDB Atlas?

Cloud-hosted MongoDB service.

Benefits:

- No local installation required
- Free tier available
- Easy scaling

---

### What is Mongoose?

ODM (Object Data Modeling) library.

Acts as:

Backend
↓
Mongoose
↓
MongoDB

Benefits:

- Easier database operations
- Schema support
- Validation support
- TypeScript integration

---

### Why connect database before starting server?

Preferred flow:

Application Start
↓
Connect Database
↓
If Success
↓
Start Express Server

Reason:

Application is not useful if database connection fails.

---

## Errors Encountered

### Error

querySrv ENOTFOUND \_mongodb.\_tcp.1928

### Cause

Invalid MongoDB URI.

Connection string still contained:

```text
<db_password>
```

instead of actual database password.

---

### Fix

Replaced placeholder:

```text
<db_password>
```

with actual MongoDB Atlas user password.

Updated:

```env
MONGODB_URI=mongodb+srv://...
```

---

Backend successfully connected to MongoDB Atlas.


Verified:

- MongoDB Atlas Connection
- Mongoose Configuration
- Environment Variables
- Database Connectivity
